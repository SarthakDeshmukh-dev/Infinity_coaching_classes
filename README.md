# Infinity Coaching Classes Website

A modern, highly responsive, and feature-rich web application built for **Infinity Coaching Classes**. This platform showcases course offerings, introduces the expert faculty, and captures student inquiries directly into a Google Spreadsheet backend.

## 📱 Website Sections
* **Introduction:** A compelling hero section introducing Infinity Coaching Classes and its mission.
* **Courses:** A breakdown of upcoming batches, subjects covered, and academic streams.
* **Faculty:** Profiles of our experienced educators and mentors.
* **Why Students Trust Infinity:** Highlights of past results, key achievements, and testimonials.
* **Enquiry & Contact:** An interactive form allowing prospective students to drop their details, alongside complete contact information and location mapping.

## 🛠️ Tech Stack & Architecture
* **Frontend:** React 18, TypeScript, Tailwind CSS
* **Build Tool:** Vite (or Create React App)
* **Backend Integration:** Google Apps Script (handles form submissions via a custom API endpoint)
* **Database / CRM:** Google Sheets (acts as a live data store for real-time student inquiries)
